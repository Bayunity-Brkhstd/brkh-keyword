Panduan Penggunaan & FAQ Proyek

StockMeta Studio by BRKH STUDIO - Microstock Batch Metadata AI

Langkah Mudah Penggunaan

  1. Konfigurasi API Key: Klik tombol Pengaturan (), masukkan 1 hingga 30 API Key Gemini (dukungan impor TXT auto-rolling).
  2. Unggah File: Klik area upload atau tarik file JPG lokal Anda ke area workspace.
  3. Pilih Preset Platform: Pilih target platform (Universal, Adobe Stock, Shutterstock, Freepik, Getty).
  4. Eksekusi Batch: Klik tombol Mulai Batch Processing. Sistem AI Vision & Buyer Demand akan bekerja secara paralel.
  5. Injeksi & Ekspor: Metadata Title, Description, dan Keywords disuntikkan secara biner ke header file JPG & file vektor EPS (jika ada). CSV/JSON dapat diekspor kapan saja.

Pertanyaan Sering Diajukan (FAQ)

Q: Apa fungsi dari menu "Kategori" dan "Preset" di toolbar atas?

1. Kategori Tema (Niche Selector): Pilihan tema khusus (misal: Text Effect, Vector Illustration, UI/UX Component, Icon Set, Isometric 3D, Social Media Poster, 3D Render, Seamless Pattern, Mascot, Logo Badge, Background Texture). Fitur ini secara cerdas mengarahkan Vision AI agar mengenali karakteristik khas visual dan menghasilkan kata kunci komersial yang tepat untuk niche tersebut.

2. Preset Platform: Menyesuaikan batas panjang Judul (60-90 karakter) serta batas kuota kata kunci otomatis sesuai aturan agensi (Universal, Adobe Stock, Shutterstock, Freepik, iStock/Getty).

Q: Apakah metadata tertulis langsung ke file fisik gambar/vektor saya?
Ya! Metadata Title, Description, dan Keywords disuntikkan secara biner langsung ke header IPTC/EXIF file JPG serta header XMP file EPS pasangan tanpa merusak kualitas piksel gambar.
Q: Bagaimana jika server Google sibuk (Error 503 High Demand)?
Sistem dilengkapi fitur Auto-Fallback cerdas. Jika server Google sibuk pada satu model, sistem otomatis beralih seketika ke model kandidat berikutnya (Gemini 2.5/1.5/2.0 Flash) tanpa menghentikan pemrosesan.
Q: Apa fungsi modul Buyer Demand & Commercial Scoring?
Sistem meriset kueri pencarian pembeli real-time dari Google & Bing, menyaring kata-kata tunggal (*single word High-CTR*), serta menempatkan 10 tag bernilai komersial tertinggi di urutan awal (aturan Adobe Stock 10-first).
